# Frecuencia Oreka App

Private, Spanish-language mobile PWA for Crystal's client and session management.

- This is an independent project and repository from `D:\Frecuencia Oreka Web`.
- Make application changes only here. Do not change the public website to implement app features.
- The website is only a visual reference. Keep independent source files, assets, dependencies, configuration and deployments; no symlinks or runtime imports from the website.
- Keep client records and private notes encrypted locally; do not commit personal data or secrets.
- Never represent Google synchronization as successful without a successful API response.
- Keep the interface in Spanish, accessible and comfortable on Android and iPhone.
- Run `npm test`, `npm run lint` and `npm run build` for functional changes.
- Keep changes local during development. Commit and push only when the user asks to synchronize after review.
